@eco
大模型天生只会「一次问答」，要变成自主 **Agent**，核心是套上**推理循环**：思考→行动→观察反复迭代直到收敛。它是 Agent 的心脏——向外调工具/记忆/知识，向内维护不断增长的*轨迹*。四种搏动方式（ReAct、Plan-Execute、Reflexion、ToT）本质是在「探索广度×纠错能力×成本」间取不同平衡点，见生态图。

@r1
**ReAct = Reasoning + Acting**，最基础形态：每轮产出 Thought/Action/Observation，观察回灌上下文触发下一轮。精髓是「让思考落地为可验证的行动」——用外部反馈校准，代价是**轨迹即上下文**、越滚越长易跑偏死循环。工程必配 **max_steps 上限**与**重复动作熔断**。机制见图。

@r2
**Plan-and-Execute** 把推理拆两段：**Planner** 一次性产出带依赖的子任务 DAG，**Executor** 逐个执行（可再开子 Agent）。收益是全局视野、强模型规划一次+小模型/并行执行省成本。关键是 **Replan 回路**——执行偏离即带新信息重规划，弥合「静态蓝图 vs 动态现实」。见图。

@r3
**Reflexion** 解决「失败怎么办」：不盲目重试，而让失败长记性——**Evaluator** 评判轨迹，模型做 **Self-Reflection** 用自然语言总结教训写入**反思记忆**，下轮注入 prompt。它用「语言化自我批评」替代 RL 奖励信号，无需更新权重即可跨尝试学习。前提是任务**可评估**。见图。

@r4
**Tree of Thoughts（ToT）** 把推理显式展开成**树**：每个关键节点生成多候选分支，评分后**保留高分、剪掉低分、必要时回溯**。借用 BFS/DFS 骨架，把 LLM 当节点扩展器+价值评估器，对试错型难题显著提升成功率。代价是 **分支数×深度 = token 与时延成倍膨胀**，属高价值场景专用「重武器」。见图。

@cmp
四范式构成**复杂度/成本/纠错能力递增**谱系：ReAct 线性单链靠即时观察、Plan-Execute 两段靠重规划、Reflexion 靠反思记忆跨尝试、ToT 树搜索靠剪枝回溯。选型第一原则：**能用简单范式就不上复杂搜索**——先问清「任务真需要多路径探索吗」。四维对照见图。

@eng
推理循环工程重心不在「更聪明」，而在「**能停、能看、能回滚**」：**循环控制**——max_steps 硬上限、重复动作熔断、token/成本/时延三重预算；**可观测性**——T/A/O 结构化落盘+Trace 回放，定位跑偏点；**鲁棒性**——工具重试退避、输出校验、高风险动作 HITL 审批、副作用幂等可回滚。铁律：**先装刹车再加油门**。四件套详见图。
