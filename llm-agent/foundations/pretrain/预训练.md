@eco

预训练是大模型的**地基**：海量无标注文本上做自监督训练，把语言规律、世界知识与初步推理压进参数，产出通用**基座模型**。三层机理框定能力上限——**训练目标**决定学什么、**数据分词**决定学得好不好、**规模法则**决定最终能到多强。见生态图。

@e1

**自监督**——从文本自身构造监督信号,真实 token 即标签,无需人工标注。两大范式:**自回归 (Causal LM)** 预测下一 token,单向、适配生成(GPT/LLaMA);**掩码 (Masked LM)** 双向还原被遮 token,语境理解强(BERT),适合判别任务。二范式对照见图。

@e2

**数据是第一生产力,质量重于数量**。流水线:质量过滤→**去重**(防记忆过拟合)→去毒隐私→按领域**配比混合**;代码数学数据显著增强推理。分词主流 **BPE**(反复合并高频相邻对,平衡词表与 OOV),**BBPE** 字节级、跨语言无 OOV。语料与切分框定认知边界,详见图。

@e3

规模法则:损失随**参数量 N、数据量 D、算力 C** 呈**幂律**平滑下降,可小规模外推,算力近似 `C ≈ 6·N·D`。**Chinchilla** 洞察——早期模型「参数过大、数据不足」,最优比约 **20 token/参数**;同算力下小模型+超量数据更强,兼顾推理成本更倾向「小模型+超量数据」。幂律曲线见图。

@cmp

三层各司其职:**训练目标**答「用什么信号学」(生成 vs 理解)、**数据分词**答「学什么、怎么表示」(清洗配比框定知识)、**规模法则**答「投入多少、能到多强」(预算翻译为性能)。目标给方向、数据给养分、规模给上限。三维对照见图。

@eng

三支柱:**规模规划**——小实验拟合幂律、按预算反推 N/D 配比、兼顾推理成本;**数据工程**——大规模去重、质量过滤、领域配比,训练前预处理落盘;**分布式训练**——数据/张量/流水线并行 + 混合精度 + ZeRO 省显存,配 checkpoint 容错与 loss 监控。权衡:算力有限先保数据质量,数据够了再放大参数,集群越大越押注容错稳定。
