@eco

自注意力本身**置换等变**——打乱输入顺序输出只跟着换位，模型感知不到「谁前谁后」。位置编码就是把「顺序」重新注入模型，让注意力算相关性时能区分同一词在句首还是句尾。三层机理：**绝对位置**给坐标、**RoPE** 让注意力直接感知相对距离、**长度外推**让训练只见短序列的模型在推理时处理更长文本。见生态图。

@p1

**绝对位置编码**为第 `pos` 个 token 生成位置向量加到词嵌入上。两种经典：**正弦编码** `PE(pos,2i)=sin(pos/10000^(2i/d))`，无需训练、能表达任意长度；**可学习编码**每位置一个可训练向量，表达力强但受限训练最大长度。共同局限在「绝对」——模型拿坐标却要从坐标差间接推相对关系，可学习编码尤其难外推（没见过的位置就无向量）。见图。

@p2

**旋转位置编码 RoPE** 换思路：不「加」而按位置角度**旋转** Q/K，位置 `m` 旋转角正比于 `m`，于是点积结果只依赖**相对距离 `n−m`**，天然相对且零额外参数。多重收益：**平移不变**、**远程衰减**、更友好的外推空间。已成 **LLaMA、Qwen、GLM** 等主流模型默认选择。见图。

@p3

**长度外推**解「训练窗口短、推理文本长」矛盾（超训练长度直接用 RoPE 会注意力崩坏）。三类方案：**位置插值 PI** 把新位置线性压回训练区间，最简单但损分辨率；**NTK-aware / YaRN** 按频段缩放旋转基（高频保细节、低频扩范围），免训练即扩数倍窗口；**ALiBi** 用与距离成正比的偏置替代显式编码、天然线性外推。常见组合「NTK/YaRN 扩基 + 少量长文本微调固化」。见图。

@cmp

三者分工清晰：**绝对位置**给起点坐标、让模型第一次知道顺序；**RoPE** 给相对关系、让注意力直接感知距离；**长度外推**给可用窗口、让模型走得比训练时更远。一句话：绝对定坐标、RoPE 定相对、外推定能走多远——三层叠加让 Transformer 既懂顺序又能读长文。四维对照见图。

@eng

三支柱：**编码选型**——新模型几乎无脑选 RoPE（相对性+零参数）；**扩窗策略**——需更长上下文优先 NTK/YaRN 免大改方案配少量长文本微调；**长文本工程**——再叠滑窗注意力、KV 缓存分页、检索压缩等系统手段。主线：短上下文用 RoPE 原生，中等扩窗用 NTK/YaRN，超长文本则编码扩窗与系统压缩双管齐下。详见图。
